# FuelPricer: Retail Fuel Pricing Analytics

A Python tool that does the core work of a fuel pricing analyst: estimate how
demand responds to price, recommend a price for each site inside competitive
guardrails, audit posted prices against that strategy, monitor cost and
market changes, administer price changes, and produce daily, weekly, and
period fuel reports for Excel and Power BI.

## Data

All data is synthetic, generated by `data_gen.py`: 8 sites, 90 days, 720 daily
records of price, cost, competitor price, and volume. It is not Circle K data
or real market data. The generator builds in a known demand elasticity
(-6.0) so the analysis can be checked, and injects a simulated tax
adjustment (+5.0 cents per litre) on day 60 to test the alert logic.

To use real data, load it into the `daily_sales` table (for example weekly
retail prices published by Natural Resources Canada).

## What it does

1. **Price elasticity** (`fit_elasticity`): log log regression of volume on
   own price relative to the competitor price, controlling for day of week
   and site. Recovers -5.78 against the true -6.0 on the synthetic data.
2. **Price recommendation** (`recommend_price`): searches prices from 3.0
   cents below to 2.0 cents above the competitor and picks the one with the
   highest expected daily gross profit under the fitted demand curve.
3. **Compliance audit** (`compliance_audit`): compares the price each site is
   posting to the recommended price and labels each site Compliant, Off
   Strategy, or Guardrail Breach.
4. **Alerts** (`cost_alerts`): flags day over day jumps in cost (2 cents or
   more) or competitor price (4 cents or more), which is how the simulated
   tax adjustment is detected.
5. **Price changes** (`change_price`): rejects any change outside the
   guardrails and records every accepted change in a change log.
6. **Reports** (`reports.py`): daily, weekly, and four week period reports by
   site with volume change against the prior window, exported to an Excel
   workbook and CSV files that load directly into Power BI.

## Setup

```
pip install -r requirements.txt
python main.py init
python main.py elasticity
python main.py recommend
python main.py audit
python main.py alerts
python main.py report weekly
python main.py change "Site 03" 158.0 "Align to strategy"
python main.py export
```

## Tests

```
python -m pytest test_fuelpricer.py
```

Covers elasticity recovery, guardrails, compliance audit statuses, price
change validation and logging, tax alert detection, reports, and export.

## Limits

The demand model is a single elasticity per market, not a full site level
model. The synthetic data has a clean, known structure, which real data will
not. Recommendations here are decision support for an analyst to review, not
automatic price changes.
